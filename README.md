# Solaria Helper

Painel completo para jogadores de World of Solaria acompanharem personagens, mercado, itens, builds, guildas e bosses em um só lugar.

## Recursos

- Mercado com filtros, comparação e análise de preços
- Página do personagem com evolução e sugestões de upgrade
- Catálogo de itens com classe, nível e origem do drop
- Build Planner e comparação de equipamentos
- Boss tracker, watchlist, alertas, metas e modo guilda
- Interface responsiva e suporte a instalação como PWA

## Como executar

Requer Node.js 22 ou mais recente.

```bash
npm install
npm run dev
```

O aplicativo ficará disponível em `http://localhost:8080`.

## Verificações

```bash
npm run typecheck
npm run build
```

## Tecnologias

React 19, TanStack Start/Router/Query, TypeScript, Tailwind CSS e Vite.
